GET /v1/documents

Lister les documents

Retourne les documents accessibles à la clé API utilisée, avec pagination par curseur. Les documents en brouillon ne sont retournés que si la clé a la portée read+write.

Paramètres de requête
Paramètre
Type
Description
space_id
string
Filtre sur un espace précis (optionnel).
tag
string
Filtre sur un tag (ex. IAM).
status
enum
published · draft · archived
cursor
string
Curseur de pagination retourné par la page précédente.
limit
integer
1 à 100 (défaut 25).
Exemple de requête
curl Copier 
curl https://api.meridian-group.com/v1/documents?tag=IAM&limit=25 \
  -H "Authorization: Bearer sk_live_••••••••4f2a"

Codes de statut
200 Requête traitée avec succès.
401 Clé API absente, invalide ou révoquée.
403 Portée insuffisante pour la ressource demandée.
429 Limite de débit dépassée — voir ci-contre.
