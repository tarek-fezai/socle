# Décision — actions du dossier et dernière modification de Référence

Date : 2026-10-15. Branche `feature/folder-page-screen`. Décisions DP-2026-10-15.

## Actions du dossier

Les actions Renommer, Déplacer, Depuis un modèle et Supprimer tiennent dans un bouton « ⋯ » de la barre d’actions, à droite de « + Nouveau document ». Le bouton n’est pas affiché à un lecteur. Supprimer n’apparaît dans le menu que si le dossier peut être supprimé, et la confirmation reste dans la page. Le bouton provisoire « Supprimer le dossier » du panneau latéral est retiré.
